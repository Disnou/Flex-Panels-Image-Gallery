# 🖼️ Flex Panels Image Gallery / Galeria de Imagens com Flexbox

[Português] Uma galeria de imagens interativa e fluida, construída para aprofundar o domínio sobre CSS Flexbox e manipulação de eventos de transição com JavaScript puro.
[English] An interactive and fluid image gallery, built to deepen the mastery of CSS Flexbox and transition event manipulation with pure JavaScript.

---

## 🇧🇷 Português

### 🚀 Tecnologias Utilizadas
* **HTML5:** Estruturação dos painéis e textos.
* **CSS3:** Uso intensivo de **Flexbox** (com `flex-grow`), transições suaves (`transition`), transformações (`translateY`) e pseudo-classes.
* **JavaScript (Vanilla):** Manipulação do DOM (`classList.toggle`) e escuta avançada de eventos (`click` e `transitionend`).

### 🧠 O que aprendi
Neste projeto, o principal foco foi entender o poder de combinar classes CSS com gatilhos do JavaScript.
* Descobri como animar a propriedade `flex` nativamente para criar painéis que se expandem fluidamente lado a lado.
* Aprendi a utilizar o evento `transitionend` no JavaScript para encadear animações, garantindo que o texto só apareça deslizando *depois* que o painel terminar de crescer.
* Entendi a diferença entre animar propriedades de layout e propriedades de transformação para evitar travamentos de renderização na tela.

### ⚙️ Como executar
1. Faça o clone deste repositório ou baixe os arquivos.
2. Abra o arquivo `photos.html` em qualquer navegador moderno.
3. Clique em qualquer um dos painéis para ver a animação acontecer!

## 🇺🇸 English

### 🚀 Technologies Used
* **HTML5:** Structuring panels and text.
* **CSS3:** Intensive use of **Flexbox** (with `flex-grow`), smooth transitions (`transition`), transforms (`translateY`), and pseudo-classes.
* **JavaScript (Vanilla):** DOM manipulation (`classList.toggle`) and advanced event listening (`click` and `transitionend`).

### 🧠 What I Learned
In this project, the main focus was understanding the power of combining CSS classes with JavaScript triggers.
* I discovered how to animate the `flex` property natively to create fluidly expanding side-by-side panels.
* I learned how to use the `transitionend` event in JavaScript to chain animations, ensuring the text only slides in *after* the panel finishes growing.
* I understood the difference between animating layout properties and transformation properties to avoid screen rendering lag.

### ⚙️ How to Run
1. Clone this repository or download the files.
2. Open the `photos.html` file in any modern browser.
3. Click on any of the panels to see the animation happen!
